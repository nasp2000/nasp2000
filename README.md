## Main projects

### [Node32-HUB](https://github.com/nasp2000/Node32-HUB)
Modular ESP32-S3/P4 firmware framework: RS232, Modbus, CAN, GRBL, sensors, web UI. One codebase, many devices via compile-time packs.

### [BeamBurin](https://github.com/nasp2000/BeamBurin) — in development
Laser engraving and cutting job editor in Rust. Imports, prepares and exports the job — never controls a machine. Pre-1.0, no release yet.

### [FreePlots](https://github.com/nasp2000/FreePlots)
Industrial statistics desktop app in Rust. Offline, MIT, one executable, no telemetry.
