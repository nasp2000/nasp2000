## Main projects

### [Node32-HUB](https://github.com/nasp2000/Node32-HUB)
Modular firmware framework for ESP32-S3 and ESP32-P4. One codebase, many devices: compile-time packs enable RS232, LPT/DB25, Modbus RTU/TCP, CAN, GRBL, sensors, email, scheduler, camera, radio and audio, all served by a web UI over Wi-Fi or wired Ethernet. Disabled modules cost zero RAM, and the same tree produces the whole family below — Node32-OEE, Rambox32, Cam-M, GcodeSender and Harmonica-BOX.

### [BeamBurin](https://github.com/nasp2000/BeamBurin) — in development
Vector drawing and job preparation for laser engraving and cutting, written in Rust. Draw shapes, paths, text and images; import SVG, DXF, HPGL, PDF and raster; assign operations per layer with speed, power, passes, kerf and tabs; preview and estimate the job; export it to the sender of your choice. Portable and offline, and it deliberately never controls a machine. Pre-1.0, no release yet.

### [FreePlots](https://github.com/nasp2000/FreePlots)
Industrial statistics as a free desktop app in Rust: editable worksheet, session report, descriptive statistics, capability, control charts, MSA, hypothesis tests, ANOVA, regression, DOE and reliability. Offline, MIT, one executable, no account and no telemetry — every report states its method, sample size and exclusions.
